Web Accessibility

Last updated: August 2026

We want every visitor to be able to use this site, including people who rely on screen readers, keyboard navigation, or reduced-motion settings.

What this site does

This site is built with accessibility in mind: readable color contrast, headings in a logical order, text alternatives on images, forms with proper labels, visible keyboard focus, and animations that switch off automatically when your device asks for reduced motion.

Found a problem?

If any part of this site is hard to use with your setup, tell us and we will fix it. Call 504-517-0012, and you can always request an estimate by phone instead of the form.
